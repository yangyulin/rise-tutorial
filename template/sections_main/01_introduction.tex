\section{Introduction} \label{sec:intro}

This is the lecture-note template for the \textbf{Robotics \& State Estimation (RiSE)} tutorials.
Copy this directory into \texttt{lectures/NN-short-name/} and use it as the starting point for a
lecture's written notes. Edit the title page (\texttt{sections\_main/00\_titlepage.tex}) with the
lecture number, topic, and instructor, then write the content as additional sections under
\texttt{sections\_main/}.

To keep notes uniform across the three instructors, please keep the overall structure (title page,
table of contents, numbered sections, optional appendix, references). Section~\ref{sec:examples}
collects the common \LaTeX{} patterns (equations, figures, custom math commands, citations) used in
these notes; delete it once you start writing real content.
